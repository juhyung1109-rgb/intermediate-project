# simulation CSV

4개 파일, 총 1,400행의 합성 검증 데이터이다. 센서의 물리 의미·설비 고장 시나리오는 검증된 메타데이터가 아니므로 실제 공정 원인으로 단정하지 않는다.

|파일|행|라벨 1|결측 센서 셀|월별 표본 수|
|---|---:|---:|---:|---|
|secom_test_batch_200811_200903.csv|500|31|13253|100/100/100/100/100|
|sim_batch_200_200904_200905.csv|200|9|5280|99/101|
|sim_batch_300_200906_200908.csv|300|22|8064|98/101/101|
|sim_batch_400_200909_200912.csv|400|12|10367|98/102/99/101|

각 파일은 `sample_id,timestamp,actual_label,feature_1..feature_590`으로 구성된다. 2009-08의 확인 불량률은 14/101=13.86%다.

웹에서 CSV를 직접 업로드하거나 프로젝트 simulation 선택 메뉴를 사용한다. 두 경로 모두 같은 검증·저장 모델 추론·행 ID 결합·기본 분석을 실행한다. 파일을 자동 학습 데이터에 추가하지 않는다.

LLM 없이 일괄 분석:

```sh
python tools/analyze_simulation.py
```

실측 분석 결과는 `artifacts/analysis_reports/README.md`와 파일별 JSON에 있다.
