SEMI-GUARD: 실시간 연동 웹앱 및 Cloud Run 구축 작업 가이드

반도체 공정(SECOM) 1~3일차 분석 산출물을 100% 연동하여, 직원/관리자 역할 분리, 2대 핵심 공정 미션(빠른 불량 센서 진단 & 노후 장비 드리프트 점검), 사내 LLM Wiki 보안 폐쇄형 챗봇, 신규 데이터 실시간 배치 시뮬레이터 및 Google Cloud Run 컨테이너 배포를 완성하는 종합 실행 매뉴얼입니다.

📌 1. 시스템 개요 & 아키텍처 (Architecture Overview)

본 시스템은 머신러닝 모델의 통계 수치에 머무르지 않고, 반도체 제조 팹(Fab) 현장에서 엔지니어와 공정 책임자가 매일 실무에 사용하는 반응형 실시간 웹 관제 플랫폼입니다.

👥 2. 역할 분리 (직원용 vs 관리자용)

사용자 권한(Role-Based Access Control)을 분리하여 불필요한 정보 노출을 방지하고 작업 집중도를 극대화합니다.

👷 [직원용: 현장 엔지니어 / 오퍼레이터] Field Engineer

설비 앞이나 클린룸 작업대에서 직관적이고 빠르게 조치할 수 있는 화면:

  • ✓ 초고속 불량 센서 진단: 웨이퍼 번호 검색 ➔ 위험도 게이지 및 5대 이상 센서 즉시 출력
  • ✓ SHAP 원인 분석 요약: 진짜 불량(#1254 단선/과전압) vs 가양성(#242 전극 마모) 해명
  • ✓ 챔버 노후화 일상 점검표: CVD/식각 드리프트 현황 확인 & 점검 체크리스트 제출
  • ✓ 공정 QA 챗봇 질의: 작업 중 발생한 센서 이상 및 조치 매뉴얼 질문
👨‍💼 [관리자용: 공정 관리자 / 품질 팀장] Fab Manager

공정 전체 수율, 모델 통계 및 설비 수명 주기를 총괄 관제하는 화면:

  • ✓ 공정 전체 수율 & 시계열 트렌드: 8월 피크(15.8%) 분석 및 7일 이동평균 관제
  • ✓ AI 모델 종합 성능 평가: 상위 20% 우선 검토 성과 (Recall 71.4%, 15/21 불량 적발)
  • ✓ 314건 혼동행렬 전수 대시보드: TP 15, FP 48, FN 6, TN 245 완벽 검증
  • ✓ 설비 드리프트 총괄 관리: 핵심 6종 센서 랭킹 및 예방정비(PM) 주기 설정
  • ✓ 산출물 다운로드 센터: 마크다운 보고서, 314건 시험 예측표(CSV), 300 DPI 차트 반출

🎯 3. 2대 핵심 공정 미션 구현 규격

반도체 제조 라인의 본질적 두 가지 요구사항을 웹앱의 가장 중심 인터페이스로 배치합니다.

1 미션 1: 빠르게 불량 센서(원인)를 찾는 것

웨이퍼 식별자(ID)를 입력하거나 원클릭 퀵버튼([🚨 진짜 불량 #1254], [🔍 가양성 오탐 #242])을 누르면 0.05초 만에 진단 결과가 렌더링됩니다.

2 미션 2: 노후화된 장비(증착/식각 센서 드리프트) 찾아 점검하기

3대 다면 통계(켄달 타우 단조성 + 누적 표준화 기울기 + 기저 이동량)로 도출된 핵심 6종 센서를 챔버별로 분류하여 일상 점검 가이드를 제공합니다.

🔥 CVD 화학기상증착 챔버 점검 기저 상승 (Upward)

대상 센서: feature_29 (+2.04σ), feature_543 (+1.78σ), feature_170 (+1.53σ)

물리적 원인: 가공 누적에 따라 반응 부산물이 챔버 내벽 및 가스 노즐에 증착(Coating)되어 RF 임피던스 및 배압 상승.

  • □ 플라즈마 건식 클리닝(NF3 In-situ Clean) 주기 20% 단축
  • □ 샤워헤드(Showerhead) 분사 노즐 탈거 및 화학 세정
  • □ 챔버 배기 조절 밸브(Throttle Valve) 응답성 점검
⚡ Dry Etch 건식 식각 챔버 점검 기저 하강 (Downward)

대상 센서: feature_104 (-1.73σ), feature_80 (-1.71σ), feature_60 (-1.49σ, -99.1% 폭락)

물리적 원인: 고밀도 플라즈마 충돌로 하부 전극 및 포커스 링이 깎여나가며 RF 전송 효율 감소 및 영점 하강.

  • □ 포커스 링(Focus Ring) 두께 측정 후 한계 마모 시 즉시 교체
  • □ 정전척(ESC) RF 매처(Matcher) 영점 재보정
  • □ feature_60 대응 전력 공급 모듈(Power Generator) 선제 교체

🧪 5. 신규 데이터 실시간 배치 시뮬레이터 (Simulator)

신규 롯(Lot) 또는 미지의 웨이퍼 센서 데이터셋(CSV)을 드래그 앤 드롭했을 때, 전처리 파이프라인과 모델이 실시간으로 정상 작동하는지 검증합니다.

⚙️ 5단계 실시간 인퍼런스 파이프라인 (`simulate_batch_inference`) 0.05초 초고속 서빙
  1. 유효 센서 정합성 체크: 입력 CSV에서 232개 유효 센서 열이 존재하는지 검증
  2. 중앙값 대체 (Imputation): 학습 데이터(Train) 정상군 중앙값으로 결측치 완벽 대체
  3. 표준화 스케일링 (Robust/Standard Scaler): 누수 없이 학습 객체 기반 변환
  4. 파생변수 생성 (`abnormal_sensor_count`): 정상 기준 2시그마 초과 센서 개수 산출
  5. 챔피언 모델 스코어링 & 순위화: 불량 확률 산출 ➔ 상위 20% 우선 검토 자동 분기 ➔ UTF-8-SIG 한글 엑셀 CSV 다운로드 버튼 제공

☁️ 6. Google Cloud Run 서버 구축 & 배포

FastAPI 기반의 경량 백엔드를 도커 컨테이너로 빌드하여 Google Cloud Run에 배포함으로써 전 세계 어디서든 안전하게 호출 가능한 서버리스 API를 구축합니다.

1) 백엔드 REST API 엔드포인트 설계

메서드 엔드포인트 설명
POST /api/chat 사내 LLM Wiki 지식 기반 챗봇 질의응답 (보안 프롬프트 적용)
POST /api/predict-batch 신규 웨이퍼 CSV 업로드 및 실시간 배치 추론
GET /api/wafer/{sample_id} 특정 웨이퍼 불량 위험도, 5대 이상 센서 및 SHAP 기여도 조회
GET /api/drift-status CVD / Dry Etch 6대 핵심 드리프트 센서 및 정비 가이드 조회
GET /api/download/{file_type} 종합 진단 보고서(MD) 및 314건 시험 예측표(CSV) 다운로드

2) Cloud Run 배포용 Dockerfile

FROM python:3.10-slim

WORKDIR /app

# 시스템 의존성 설치
RUN apt-get update && apt-get install -y --no-install-recommends \
    build-essential \
    && rm -rf /var/lib/apt/lists/*

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# 코드 및 모델 아티팩트 복사
COPY . .

ENV PORT=8080
EXPOSE 8080

CMD ["uvicorn", "server.app:app", "--host", "0.0.0.0", "--port", "8080"]

3) 1클릭 Cloud Run 배포 스크립트 (`deploy_cloud_run.sh`)

#!/bin/bash
