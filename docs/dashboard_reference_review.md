원격 서비스에서 지식 등록, CSV 반영, 점검 발령·보고·승인 전송은 실행하지 않았다. 실제 상태 변경 검증은 새 로컬 서비스에서 진행한다.

발견한 정합성 문제: 관제 선택 메뉴의 7월 16건과 화면의 17건이 다르고, 월 선택 후 혼동행렬 상세 수치는 바뀌어도 일부 총합·설명은 814건으로 남는다. 기간별 실행의 일부 빠른 선택 버튼도 고정된 전역 값으로 돌아간다. 로컬 구현은 선택 데이터셋·기간·검토 비율 하나로 집계와 행 분류를 다시 계산한다.

센서의 물리 의미와 고장 원인은 검증된 매핑 없이 복제하지 않는다. SHAP과 센서 편차는 실제 모델·원본 센서로 계산한다. 역할 버튼은 로컬 업무 흐름 시연용이며 계정 권한 검증을 대신하지 않는다.

## 로컬 직접 조작 결과

- 여름 CSV로 변경하고 8월을 선택한 뒤 검토 비율을 25%로 조정했다. 101행 중 26행을 선정하고 TP 6·FP 20·FN 8·TN 67로 합계가 일치했다.
- FN 8건을 필터링하고 첫 표본 2990의 진단 버튼을 눌러 같은 범위의 순위 55, 원본 센서 편차와 실제 SHAP을 확인했다.
- TP/FP 비교와 FP 단독 모드, 월별 수율과 7일 이동 통계를 확인했다.
- feature_104 분포 변화에서 로컬 시연 지시를 발령하고 체크 3개·보고 소견 작성·보고 제출·관리자 승인·승인 이력을 확인했다. 실제 설비 점검을 수행한 기록은 아니다.
- Gemini에 선택 8월만 집계하도록 질의해 Tool 1회, 101행·확인 불량 14건·13.86% 답변을 확인했다.
- SECOM 시험 314행 불러오기, summer CSV 파일 업로드, Markdown과 예측 CSV 다운로드, 현재 로컬 주소 QR을 직접 확인했다.
- 기간·소유 범위·대화 격리·점검 전이를 포함한 자동 검증 40개를 통과했다.
