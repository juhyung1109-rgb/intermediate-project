02 3대 핵심 엔지니어링 원칙

1. 시간 누수(Data Leakage) 차단 Security

시간 정보(타임스탬프)는 사후 공정 추세 분석에만 사용하며, 8:2 층화 분리 및 Train 전처리 파이프라인의 기준선을 절대 침범하지 않습니다.

2. 객관적 드리프트 통계 Statistics

센서명이 익명화되어 있으므로 임의로 "챔버 온도"나 "가스 압력"으로 단정하지 않고, 시간 순위 상관계수(Drift Score) 기반으로 장비 열화 경향을 기술합니다.

3. Single Source of Truth Integrity

웹 화면에 표출되는 수치(Recall 71.4%, 선정 수 63개, 혼동행렬 314건)와 다운로드되는 보고서의 수치는 동일한 결과 객체로부터 생성되어 단 1건의 오차도 없습니다.

03 Step 1: 공정 시계열 & 불량 집중 변곡점 분석

SECOM 데이터의 타임스탬프(2008년 7월 19일 ~ 10월 10일)를 분석하여 특정 시점(예: 장비 부품 교체 직후나 특정 주차)에 불량이 집중 발생하는 패턴을 진단합니다. 

def analyze_timeseries_trend(df_labels):
    """월별/주별 생산량 및 불량률 시계열 추이 분석"""
    df = df_labels.copy()
    df['timestamp'] = pd.to_datetime(df['timestamp'])
    df = df.sort_values('timestamp').reset_index(drop=True)

    # 일별 집계 및 7일 롤링 평균 불량률
    df['date'] = df['timestamp'].dt.date
    daily_summary = df.groupby('date').agg(
        total_wafers=('label', 'count'),
        fail_wafers=('label', 'sum')
    ).reset_index()
    daily_summary['fail_rate'] = (daily_summary['fail_wafers'] / daily_summary['total_wafers']) * 100
    daily_summary['rolling_7d_fail_rate'] = daily_summary['fail_rate'].rolling(window=7, min_periods=1).mean()

    return daily_summary

04 Step 2: 챔버 열화 & 센서 드리프트(Sensor Drift) 탐색

시간 경과에 따라 센서의 중심값(Mean)이나 분산이 서서히 이동하는 현상은 반도체 식각/증착 챔버 내벽의 파티클 누적이나 전극 마모를 의미합니다. 

def detect_sensor_drift(df_features, df_labels, valid_features, top_n=5):
    """시간 축에 따른 피어슨 상관계수를 계산하여 드리프트 민감 센서 선별"""
    df = pd.merge(df_features[['sample_id'] + valid_features], df_labels[['sample_id', 'timestamp']], on='sample_id').sort_values('timestamp')
    time_indices = np.arange(len(df))
    drift_records = []

    for sensor in valid_features:
        series = df[sensor].fillna(df[sensor].median())
        if series.std() > 1e-6:
            corr = np.corrcoef(time_indices, series)[0, 1]
            drift_records.append({
                'sensor_id': sensor,
                'drift_score': abs(corr),
                'direction': '상승 드리프트 ⬆️' if corr > 0 else '하강 드리프트 ⬇️'
            })

    return pd.DataFrame(drift_records).sort_values(by='drift_score', ascending=False).head(top_n)
