02 핵심 설계 4대 원칙

1. 결정론적 동점 순위 (Tie-Breaking) C03

로지스틱 회귀에서 동일한 위험 점수가 나올 경우, risk_score 내림차순 후 sample_id 오름차순(first 방식)으로 고정 정렬하여 언제 실행해도 순위가 100% 동일하게 재현되도록 보장합니다.

2. 표본 수 올림 (math.ceil) 규격 C03

기획서 명세에 따라 상위 $k\%$ 표본 선정 시 $N_{selected} = \lceil N \times \text{ratio} \rceil$를 적용합니다. (Test 314건의 20% = $314 \times 0.20 = 62.8 \rightarrow$ 63개 정확 일치)

3. 정상 참고 구간 (5~95 백분위) C04

공정 장비의 물리적 하드웨어 Spec이 제공되지 않으므로, '장비 절대 공차'가 아닌 '데이터 기반 학습 정상 집단의 통계적 분포(5~95 Percentile)'임을 UI에 명확히 표기합니다.

4. 분류와 순위 성과의 분리 C06

혼동행렬의 기본 전수 합계는 $TP+FP+FN+TN=314$건이어야 하며, 기본 임계값 0.5 분류 성과와 상위 20%(63개) 우선 검토 시의 비즈니스 성과를 엄격히 분리하여 표시합니다.

03 Step 1: 위험도 예측 & 결정론적 동점 순위 로직

누수 방지 원칙에 따라 Train 데이터로만 피팅된 preprocessor.joblib와 baseline_model.joblib를 로드하여 Test 세트 314건의 위험 점수(Risk Score)를 추론하고, 기획서 C03 규격에 맞는 안정적 동점 순위를 부여합니다. 

import math
import joblib
import numpy as np
import pandas as pd

def predict_risk(preprocessor_path, model_path, df_features, df_labels):
    # 1. 영속화 객체 로드 (전처리 파이프라인 & 232개 유효 센서 명단)
    prep_dict = joblib.load(preprocessor_path)
    preprocessor = prep_dict['preprocessor']
    valid_features = prep_dict['valid_features']
    model = joblib.load(model_path)

    # 2. Test 피처 정렬 및 전처리 (누수 없이 Train 파이프라인 적용)
    test_sample_ids = df_labels['sample_id'].values
    df_test_feat = df_features[df_features['sample_id'].isin(test_sample_ids)].copy()
    df_test_feat = df_test_feat.set_index('sample_id').loc[test_sample_ids]
    
    X_test_scaled = preprocessor.transform(df_test_feat[valid_features])

    # 3. 불량 위험 점수(Risk Score) 산출 (클래스 1의 예측 확률)
    risk_scores = model.predict_proba(X_test_scaled)[:, 1]

    df_pred = pd.DataFrame({
        'sample_id': test_sample_ids,
        'actual_label': df_labels['label'].values,
        'risk_score': risk_scores
    })

    # 4. 결정론적 동점 처리: risk_score 내림차순 -> sample_id 오름차순 (C03)
    df_pred = df_pred.sort_values(
        by=['risk_score', 'sample_id'],
        ascending=[False, True]
    ).reset_index(drop=True)
    df_pred['risk_rank'] = range(1, len(df_pred) + 1)

    # 5. 상위 20% 플래그 부여 (ceil 규칙: 314 * 0.20 = 62.8 -> 63개)
    top20_cutoff = math.ceil(len(df_pred) * 0.20)
    df_pred['is_top20pct'] = df_pred['risk_rank'] <= top20_cutoff

    return df_pred

04 Step 2: Top-k% 동적 성과 지표 산출 로직

사용자가 슬라이더로 검토 비율(5%~50%)을 동적으로 변경할 때, 해당 비율 내에서 검출된 불량 웨이퍼 수와 Recall@k% 및 Precision@k%를 실시간으로 재계산합니다. 

import math
from sklearn.metrics import average_precision_score

def calculate_review_metrics(df_predictions, ratio=0.20):
    n_total = len(df_predictions)
    n_fails_total = (df_predictions['actual_label'] == 1).sum()
    n_selected = math.ceil(n_total * ratio)

    selected_subset = df_predictions[df_predictions['risk_rank'] <= n_selected]
    n_detected_fails = (selected_subset['actual_label'] == 1).sum()

    recall_at_k = (n_detected_fails / n_fails_total if n_fails_total > 0 else 0.0) * 100
    precision_at_k = (n_detected_fails / n_selected if n_selected > 0 else 0.0) * 100
    ap_score = average_precision_score(df_predictions['actual_label'], df_predictions['risk_score'])

    return {
        'review_ratio': ratio,
        'review_ratio_pct': ratio * 100,
        'n_total': n_total,
        'n_selected': n_selected,
        'n_fails_total': n_fails_total,
        'n_detected_fails': n_detected_fails,
        'recall_at_k': recall_at_k,
        'precision_at_k': precision_at_k,
        'average_precision': ap_score
    }

05 Step 3: 정상 참고 분포 비교 엔진

특정 고위험 웨이퍼를 선택했을 때, 학습 정상 집단(1,170건)의 센서별 5~95 백분위 및 중앙값과 비교하여 정상 범위에서 가장 크게 이탈한 핵심 센서 5종을 자동으로 발굴합니다.

⚠️ 무결성 보존: 원측정값에 결측이 있었는지 여부(was_imputed)를 반드시 기록하여, 중앙값으로 대체된 값인지 실제 측정된 값인지를 공정 엔지니어가 명확히 구별할 수 있도록 합니다. 
def compare_reference(df_features_raw, train_normal_ids, selected_sample_id, valid_features, top_n=5):
    df_raw_indexed = df_features_raw.set_index('sample_id')
    train_normal_feats = df_raw_indexed.loc[df_raw_indexed.index.isin(train_normal_ids), valid_features]

    # 1. 학습 정상 통계량 계산
    norm_median = train_normal_feats.median()
    norm_mean = train_normal_feats.mean()
    norm_std = train_normal_feats.std().replace(0, 1e-6)
    norm_p05 = train_normal_feats.quantile(0.05)
    norm_p95 = train_normal_feats.quantile(0.95)

    # 2. 선택 샘플 및 편차 계산
    sample_series = df_raw_indexed.loc[selected_sample_id, valid_features]
    is_missing = sample_series.isna()
    imputed_values = sample_series.fillna(norm_median)

    z_scores = (imputed_values - norm_mean) / norm_std
    top_deviated_sensors = z_scores.abs().sort_values(ascending=False).head(top_n).index.tolist()

    # 3. 5대 이상 센서 상세 비교 테이블 구성
    rows = []
    for sensor in top_deviated_sensors:
        rows.append({
            'sensor_id': sensor,
            'original_value': np.nan if is_missing[sensor] else round(float(sample_series[sensor]), 4),
            'imputed_value': round(float(imputed_values[sensor]), 4),
            'was_imputed': bool(is_missing[sensor]),
            'normal_p05': round(float(norm_p05[sensor]), 4),
            'normal_median': round(float(norm_median[sensor]), 4),
            'normal_p95': round(float(norm_p95[sensor]), 4),
            'z_score': round(float(z_scores[sensor]), 2),
            'is_out_of_bounds': (imputed_values[sensor] < norm_p05[sensor]) or (imputed_values[sensor] > norm_p95[sensor])
        })
    return pd.DataFrame(rows)
