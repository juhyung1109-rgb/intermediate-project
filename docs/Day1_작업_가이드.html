02 중요! 591열 오류 원인 규명 및 590열 정합성 확립

🚨 데이터 로드 오류 원인 분석:
UCI SECOM 원본 파일(secom.data)은 공백(Space)으로 구분되어 있습니다. 단순 read_csv(sep=" ")로 읽으면 행 끝에 붙은 불필요한 후행 공백(Trailing Space) 때문에 존재하지 않는 가상의 591번째 빈 열(NaN)이 강제로 생성됩니다.
이를 방지하기 위해 정규식 공백 구분자 sep=r"\s+"를 반드시 사용하여 정확히 590열로 로드해야 합니다. 
# 591열 버그를 방지하는 정확한 원본 로드 코드
import pandas as pd

# sep=r"\s+"를 사용하면 연속 공백 및 후행 공백이 자동으로 정리되어 정확히 590열로 읽힙니다.
features = pd.read_csv("data/raw/secom.data", sep=r"\s+", header=None)

03 엄격한 데이터 누수(Data Leakage) 원천 차단 3대 원칙

머신러닝에서 가장 치명적인 실수는 "전체 데이터(1,567건)를 한꺼번에 결측치 대체하거나 스케일링한 후 분할하는 것"입니다. 이 경우 Test 데이터의 분포 정보가 학습 모델에 유출되어 실무 환경에서 심각한 과적합과 성능 폭락을 일으킵니다.

전처리 단계 🚨 잘못된 방법 (Leakage 발생) ✅ 올바른 방법 (철저한 분리)
결측치 대입 (Imputation) 전체 1,567개 행의 중앙값을 구해 채운다. Train(1,253건)의 중앙값만 계산하여 Test 세트에 동일 적용.
상수 열 제거 (Dropping) 전체 데이터에서 고유값이 1개인 센서를 제거. Train 세트 내에서만 고유값이 1개인 열을 탐색하여 삭제.
피처 스케일링 (Scaling) 전체 센서의 평균/표준편차로 스케일링. scaler.fit(X_train) 후 scaler.transform(X_test) 수행.

05 Step 1: 데이터 무결성 검증 및 전처리 파이프라인

원본 데이터셋을 로드하여 590열 정합성을 확인하고, sample_id를 부여하며, 라벨을 표준 머신러닝 형식(정상 0, 불량 1)으로 변환하여 data/processed/에 영구 저장합니다. 

# [Step 1] src/data_loader.py 핵심 발췌
def load_and_preprocess_secom():
    # 1. 590열 정확한 로드
    features = pd.read_csv("data/raw/secom.data", sep=r"\s+", header=None)
    assert features.shape == (1567, 590), f"형상 불일치: {features.shape}"
    
    # 2. 고유 sample_id 및 sensor 컬럼명 부여
    features.columns = [f"feature_{i+1}" for i in range(590)]
    sample_ids = [f"sample_{i+1:04d}" for i in range(len(features))]
    features.insert(0, "sample_id", sample_ids)
    
    # 3. 라벨 및 타임스탬프 변환
    labels_raw = pd.read_csv("data/raw/secom_labels.data", sep=r"\s+", header=None)
    y = labels_raw[0].map({-1: 0, 1: 1}).values  # -1 -> 0, 1 -> 1
    timestamps = pd.to_datetime(labels_raw[1], format="%d/%m/%Y %H:%M:%S")
    
    df_labels = pd.DataFrame({
        "sample_id": sample_ids,
        "label": y,
        "timestamp": timestamps
    })
    
    # 4. 저장
    features.to_csv("data/processed/secom_features.csv", index=False)
    df_labels.to_csv("data/processed/secom_labels.csv", index=False)
    return features, df_labels

06 Step 2: 층화 분리(Stratified Split 8:2) 및 인덱스 영구 고정

불량률이 6.64%로 극도로 불균형하므로, train_test_split(..., stratify=y, random_state=42)을 통해 Train(1,253건)과 Test(314건)의 불량률을 균일하게 보존하고 인덱스를 영구 고정합니다. 

# [Step 2] src/split_data.py 핵심 발췌
from sklearn.model_selection import train_test_split

def split_and_save_indices():
    df_labels = pd.read_csv("data/processed/secom_labels.csv")
    train_df, test_df = train_test_split(
        df_labels,
        test_size=0.2,
        stratify=df_labels["label"],
        random_state=42
    )
    
    train_df[["sample_id", "label"]].to_csv("artifacts/train_indices.csv", index=False)
    test_df[["sample_id", "label"]].to_csv("artifacts/test_indices.csv", index=False)
    print(f"Train 불량률: {train_df['label'].mean()*100:.2f}% | Test 불량률: {test_df['label'].mean()*100:.2f}%")

09 Step 5: 학습 데이터 전처리 파이프라인 (`artifacts/preprocessor.joblib`)

Train 데이터(1,253건)를 기준으로 결측률 50% 초과 센서(28개)와 상수 센서(116개)를 제거하고, 중앙값 대입과 표준 스케일러로 이어지는 Scikit-Learn Pipeline을 영구 직렬화하였습니다. 

# [Step 5] 전처리 파이프라인 구축 및 영속화 코드
import joblib
import pandas as pd
from sklearn.pipeline import Pipeline
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler

# 1. Train 인덱스 기준 분리
df_features = pd.read_csv("data/processed/secom_features.csv")
train_ids = pd.read_csv("artifacts/train_indices.csv")["sample_id"].values
X_train_raw = df_features[df_features["sample_id"].isin(train_ids)].drop(columns=["sample_id"])

# 2. Train 기준 50% 초과 결측 센서 식별 및 제거 (24개)
high_missing_cols = X_train_raw.columns[X_train_raw.isna().mean() > 0.50].tolist()
X_step1 = X_train_raw.drop(columns=high_missing_cols)

# 3. Train 기준 상수 센서 식별 및 제거 (116개)
constant_cols = X_step1.columns[X_step1.nunique(dropna=True) <= 1].tolist()
X_step2 = X_step1.drop(columns=constant_cols)

# 4. 상관계수 필터링 (|r| > 0.85, 218개 모사/복제 센서 제거 -> 다중공선성 해소)
imputer_temp = SimpleImputer(strategy="median")
X_temp = pd.DataFrame(imputer_temp.fit_transform(X_step2), columns=X_step2.columns, index=X_step2.index)
corr_matrix = X_temp.corr().abs()
upper = corr_matrix.where(np.triu(np.ones(corr_matrix.shape), k=1).astype(bool))
to_drop_corr = [col for col in upper.columns if any(upper[col] > 0.85)]
X_step3 = X_step2.drop(columns=to_drop_corr)
valid_features = X_step3.columns.tolist() # 232개 핵심 유효 센서

# 5. Scikit-Learn 파이프라인 (중앙값 대입 -> 표준화 스케일링)
preprocessor = Pipeline([
    ("imputer", SimpleImputer(strategy="median")),
    ("scaler", StandardScaler())
])
X_train_processed = preprocessor.fit_transform(X_step3)

# 6. 영구 직렬화
joblib.dump({
    "preprocessor": preprocessor,
    "dropped_high_missing": high_missing_cols,
    "dropped_constant": constant_cols,
    "dropped_correlated": to_drop_corr,
    "valid_features": valid_features
}, "artifacts/preprocessor.joblib")
print(f"✅ 전처리 파이프라인 구축 완료: 유효 센서 {len(valid_features)}개 보존")
