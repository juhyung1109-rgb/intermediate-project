01

SEMI-GUARD 전체 서비스 & 보안 아키텍처

모바일 PWA 앱, Firebase Auth 관문, Cloud Run 백엔드, Vertex AI, 12대 Python 분석 도구 및 데이터 저장소가 유기적으로 연결된 전체 구조도입니다.

  1. 모바일 PWA 및 클린룸 태블릿 접속

    현장 엔지니어와 공정 관리자는 기기 구분 없이 PWA 브라우저로 접속합니다. 클라이언트에는 어떤 Gemini 비밀키나 서비스 계정 키도 보관되지 않습니다.

  2. Firebase Authentication & 가입 승인 게이트

    Firebase SDK를 통해 사내 이메일로 가입/로그인합니다. 서버는 사용자의 승인 상태(`isApproved`)를 확인하여, 승인되지 않은 계정은 메인 화면 진입을 원천 차단합니다.

  3. Cloud Run 백엔드 & 12대 Python 도구 격리

    Python 3.11 FastAPI 기반 백엔드가 요청을 받아 데이터셋 소유권을 격리하고, Gemini와 통신하며 초고속 불량 센서 진단실(Triage), SHAP Waterfall, 센서 드리프트, 챔버 예지보전(PdM) 등 12대 도구를 실행합니다.

  4. 이중 데이터 저장소 (SQLite & Cloud Firestore)

    고속 실시간 분석 캐시는 SQLite(`runtime/analysis.sqlite3`)로 초저지연 서빙하고, 사원 프로필 및 인가 정보는 Cloud Run 내부 메타데이터 토큰으로 Google Cloud Firestore(`project` DB)에 안전하게 영구 저장합니다.

02

신규 사원 회원가입 승인제 라이프사이클

사내 보안 규정에 따라 사원이 임의로 시스템 권한을 획득할 수 없으며, 공정 관리자(Admin)가 명시적으로 승인해야만 시스템 로그인이 완료됩니다.

단계주체실행 작업보안 상태 및 결과
1. 가입 신청신규 사원이메일, 비밀번호, 성명, 희망 역할 입력 후 신청계정 생성 즉시 status='pending' 지정 후 자동 강제 로그아웃(세션 차단)
2. 미승인 차단미승인 사원승인 전 이메일/비밀번호로 로그인 시도서버가 isApproved=False 확인 즉시 세션 해제, [승인 대기 중] 경고 노출 및 진입 차단
3. 관리자 심사공정 관리자관리자 허브 접속 ➔ [👥 사원 가입 승인] 센터 오픈대기 명단 확인 후 [✅ 승인] 클릭 ➔ status='approved' 실시간 업데이트
4. 인가 및 로그인승인된 사원로그인 재시도인가 확인 완료 ➔ enterApp('engineer') 정상 진입 및 관제 센터 이용 허용
03

12대 Python 분석 도구 실행 제어 루프

Gemini 3.8 Flash가 물리 도구를 직접 실행하지 않고, Cloud Run의 AnalysisAgent가 화이트리스트 스키마로 인자를 정규화하고 병렬 실행합니다.

임의 코드 및 SQL 실행 차단 (AGENTS.md 준수): Gemini는 rank_samples, explain_sample, sensor_drift, correlate 등 사전 정의된 12대 Tool의 함수명과 JSON 인자만 제안할 수 있으며, 서버가 유효성을 검증한 뒤 내부 알고리즘으로 계산하여 수치 왜곡 없이 회신합니다.

src/data_analysis/agent.py · 도구 실행 통제 핵심
# 1. 모델에 12대 Tool 스키마 전달 (Function Declarations)
gen_config = {
    "system_instruction": instructions,
    "tools": [types.Tool(function_declarations=declarations)],
    "automatic_function_calling": types.AutomaticFunctionCallingConfig(disable=True)
}

# 2. 모델이 제안한 도구 호출(calls)을 서버가 직접 검증 및 실행
for call in calls:
    args = normalize_integers(call.name, call.args or {})
    result = tools.execute(call.name, args)  # 격리된 데이터셋 범위에서 안전 실행
    outputs.append(types.Part(function_response=types.FunctionResponse(name=call.name, id=call.id, response=result)))

# 3. 계산된 실제 수치를 모델에 돌려주어 환각(Hallucination) 없는 최종 답변 생성
contents.append(types.Content(role="user", parts=outputs))
